# 전투 기술 선택창 한글판 배치

2026-10-07. 기준: 사용자 비교 이미지와 Gold/OldGold의 MoveSelectionScreen 좌표.

## 채택한 범위

- 일반 기술 선택: 왼쪽 창 `(0,8)` 내부 8×8, 이름 기준행 `(2,10/12/14/16)`.
- 커서: `(1,10)`부터 두 줄 간격. SELECT 교환 표시도 동일 간격.
- PP/정보 창: `(9,12)` 내부 9×4, PP `(13,13)`, 기술타입 `(10,15)`,
  `/` `(14,16)`과 타입 이름 `(15,16)`. 사용자 화면 확인 후 함께 오른쪽으로 1타일 이동.
- 회복약 기술 선택은 한글판과 같이 오른쪽 창 `(10,8)`, 이름 `(12,10)`부터 두 줄 간격.
- 일반 전투와 연결된 적 기술 선택도 동일 리스트 출력 경계를 사용한다.
- 모바일 전투의 별도 선택 함수는 유지한다.

## 번역과 보호 조건

영문 기술 이름은 7칸의 이름 영역에 들어가지 않으므로 전투 창 전용 한글 테이블을 추가한다.
OldGold의 251개 이름을 기술 ID 순서로 그대로 복사했다. 공백과 옛 표기도 보존한다.
양쪽 move_constants.asm의 const ID 배열 일치와 모든 이름의 최대 7칸을 정적으로 확인했다.
전투 창의 타입 이름도 OldGold의 TypeNames 표기를 사용한다.

기존 GetName은 짧은 공용 버퍼를 복사하며, 표시용 한글 escape는 한 음절당 3바이트다.
따라서 기술 이름을 공용 테이블에 교체하면 긴 이름이 잘릴 수 있다.
이번에는 별도 ROMX 섹션의 포인터 테이블에서 PlaceString으로 직접 출력한다.
공용 MoveNames·GetName·RAM 레이아웃·기술 상수·성능·PP 계산은 변경하지 않는다.
다른 화면/대사의 영문 기술명은 이번 작업의 변경 대상이 아니다.

Gold/OldGold의 기술 정보 코드에는 위력/물리·특수 분류 등 개조 기능이 포함되어 있다.
이 코드는 가져오지 않는다. PP와 기존 크리스탈 타입만 표시한다.
봉쇄 안내는 대응 OldGold 문구를 사용한다. 사용자 이미지의 ‘기술타입’을 고정 라벨로 사용한다.

## 구현 파일

- engine/battle/core.asm: 창/커서/교환 표시/PP 좌표와 표시 라벨.
- engine/battle/korean_move_text.asm: 버퍼를 거치지 않는 기술 목록·타입 출력과 한글 테이블.
- main.asm: 별도 Korean Battle Move Text ROMX 섹션 연결.

## 검증

정적: 기술 ID 251개 대응, 원본 이름 문자열 일치, 최대 폭, charmap 공급,
두 줄 커서 간격, PP 및 타입 좌표, diff 공백 검사를 확인한다.
ROM 빌드와 실행 확인은 사용자 수행이며 완료로 간주하지 않는다.

실행 확인: 1~4개 기술 목록, 긴 이름, 빈 슬롯, PP 0/최대 PP, 봉쇄 상태,
상하 랩 이동, SELECT 순서 교환 후 PP 대응, B 취소 후 HUD, 회복약 기술 선택,
일반 통신/포획 시범의 기존 동작. 모바일은 별도 유지 경로로 검증 필요.
