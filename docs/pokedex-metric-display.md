# 도감 상세 화면: 한글 키·무게와 영문 설명/메뉴

이 문서는 수치 이식 당시의 기록이다. 이후 승인된 한글 분류·설명 및 1페이지 구조는 `pokedex-gold-description.md`를 따른다.

## 범위와 근거

- 상세 화면의 `키`, `무게`는 한글판처럼 m/kg로 표시한다.
- 분류명, 설명문, PAGE/AREA/CRY/PRNT는 기존 영문을 유지한다.
- Crystal의 기존 수치는 피트·인치와 0.1파운드 단위다. 단위 문자만 바꾸지 않는다.
- 251개 대응 파일의 `dw` 두 값만 oldgold에서 가져왔다. gold와 oldgold의 해당 수치는 모두 같다.
- 예: 치코리타 `211, 140` → `9, 64`, 즉 `0.9m / 6.4kg`.
- 종 상수, 도감 순서, 설명문, 저장 형식은 바꾸지 않았다. 각 수치 레코드는 기존과 같은 4바이트다.

## 표시 경로

- `Pokedex_DrawDexEntryScreenBG`: 키/무게와 영문 하단 안내를 `PlaceString`으로 출력한다.
  기존의 raw tile 복사는 한글 캐시가 영문 타일을 재사용할 때 깨질 수 있다.
- 메뉴 화살표 `$3b`는 그래픽으로 직접 출력한다. 메뉴 좌표와 동작은 그대로다.
- `DisplayDexEntry`: dm/hg 데이터를 소수점 한 자리 m/kg로 표시한다.
- 키는 x14~17, m은 x18; 무게는 x12~16, kg는 x17~18이다.
- 수치를 출력하기 전에 해당 영역을 지워 작은 값 앞에 미확인 `?`가 남지 않게 한다.
- 한글 라벨은 기존 한글 렌더러의 상단 타일까지 사용한다. 키는 6~7행, 무게는 8~9행이며 설명문 구역과 겹치지 않는다.

## 검증 상태

- 정적 확인: 251개 수치가 참조와 일치하고, 도감 데이터 변경은 `dw` 행에만 한정됨.
- 빌드와 실제 게임 검증은 사용자 담당이며 아직 결과를 받지 않았다.

## 사용자 테스트

1. 잡은 치코리타: `0.9m / 6.4kg`, 고스트: `1.5m / 40.5kg`.
2. 롱스톤: `8.8m / 210.0kg`, 잠만보: `2.1m / 460.0kg`.
3. 보았지만 잡지 않은 종: 미확인 표시 유지, 단위는 m/kg.
4. PAGE 전환, 다른 종 선택, AREA에서 복귀 후 키/무게와 영문 메뉴가 유지되는지 확인.
5. 포획 직후 도감 등록 화면 및 목록 화면으로 복귀했을 때의 회귀 확인.
