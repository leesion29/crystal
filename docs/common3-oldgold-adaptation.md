# common_3.asm OldGold 참고 번역

## 범위

앞선 공통 구조 46개 이식 후 보류한 39개 라벨을 대상으로 검토했다.
그중 실제 문장이 있는 37개를 Crystal 원문의 뜻에 맞춰 번역했다.
`_GearTodayText`와 `_WaitButtonText`는 문장 없이 요일 출력/버튼 대기만
수행하므로 Crystal 코드를 유지했다.

이후 파일 전체의 미번역 문장 126개를 추가로 번역했다.
OldGold `common_1.asm`, `common_2.asm`, `common_3.asm`을 참고했으며,
상점/도구/진화 등 기존 표현은 활용하고 Crystal 전용 감정/모바일/카드 폴더/
배틀타워/서머타임 안내는 원문의 뜻을 살려 직접 번역했다.
각 단계 시작 전에 이미 한국어였던 블록은 유지했다.

기준은 Crystal `data/text/common_3.asm`의 영문 원문이며,
OldGold의 같은 라벨에 있는 한국어 표현을 최대한 따른다.
`#MON`은 `포켓몬`, `#GEAR`는 `포켓기어`로 표기한다.
참고 파일은 작업 시에만 읽었으며, Crystal 빌드에서 불러오지 않는다.

## 원문 차이를 반영한 표현

- `_CardFlipShuffledText`: 이미 섞었다는 Crystal 원문에 맞춰
  `카드를 섞었습니다`로 쓴다.
- `_BallSentToPCText`: 목적지를 `이수재의 PC`로 명시한다.
- `_NewDexDataText`: 새 데이터가 도감에 추가되었다는 완료형을 유지한다.
- `_ItemBelongsToSomeoneElseText`: OldGold의 보관품 표현 대신
  Crystal의 다른 사람 소유라는 뜻을 유지한다.
- `_ItemStatRoseText`: 소비 경로가 비타민의 기초 포인트 증가이므로
  OldGold의 `기초 포인트가 올라갔다!`를 따른다.
- `_AskDeleteMoveText`: 선택한 기술을 잊게 할지 묻는 내용을 명시한다.
- `_ItemCantGetOnText`, `_BallBoxFullText`: 현재 사용할 수 없다는 뜻을 유지한다.
- `_PokegearAskDeleteText`: 삭제 대상이 전화번호임을 명시한다.

## 제어와 배치

Crystal의 RAM 버퍼 주소, 숫자 출력 인수, 효과음, 일시 정지,
버튼 대기, `text_low`, `done`/`prompt`/`text_end`를 유지한다.
`text_start`는 문자열을 출력하는 `text`와 같은 TX_START 명령이므로,
빈 문자열 시작 뒤에 조사 등을 출력해야 하는 항목은 `text`로 표현한다.
행/문단/스크롤 명령은 한국어 어순과 창 너비에 맞춰 배치한다.
원래 있던 미참조 `text_end`도 유지한다.

창의 내부 너비는 18타일이다. 영문 닉네임은 최대 10글자,
기술/도구 이름 버퍼는 최대 12글자도 고려하여 조사와 문장을 배치한다.
포획 및 기술 습득 안내는 긴 이름 뒤의 문장을 다음 줄로 스크롤한다.

## 확인 범위

수정 전 블록과 비교해 변경 범위, 기존 번역 보존, RAM/숫자 출력 인수,
효과음/대기/종료 명령 및 플레이어 이름 토큰을 검사한다.
일반/디버그 `data/text/common.asm` 조립을 검사한다.
최종 화면 배치와 스크롤 속도는 에뮬레이터에서 포획, 기술 습득/망각,
도구 사용, 동전 케이스 경로를 확인해야 한다.
파일 전체에서 영문 문장을 가진 미번역 블록은 0개다.
`PC`, `N64`, 플레이어 이름 등 표시용 식별자와 제어 토큰은 유지한다.
실제 화면 배치와 배포 검증 완료를 의미하지 않는다.
